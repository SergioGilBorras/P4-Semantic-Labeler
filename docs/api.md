# HTTP contract V1

Base path: `/v1`. JSON UTF-8, except file upload which is `multipart/form-data`. `GET /health` and autogenerated OpenAPI `/openapi.json` are available without an API key; sensitive generation routes support Bearer authentication if `P4_LABELER_API_KEY` is set.

## POST /v1/labels

```json
{
  "subject": {
    "kind": "method", "name": "cache_invalid", "module": "cache.manager",
    "class_name": "CacheManager", "signature": "def cache_invalid(self, key: str) -> bool"
  },
  "context": {
    "documentation": "A true value means the cache entry is invalid.",
    "source_code": "def cache_invalid(self, key):\n    return not self.cache.is_valid(key)",
    "text": null, "before": null, "after": null, "purpose": "navigation",
    "title": null, "document_type": null
  },
  "output_type": "title", "min_chars": 15, "max_chars": 35, "style": "technical", "language": "en"
}
```

Only `subject.name` is required. The other fields have defaults. `subject.kind` is a generic identifier (e.g. `function`, `method`, `class`, `document`, `concept`) with no domain-dependent behavior. The extensible `style` is a slug, not a fixed finite enum. `language` is validated against the syntax of a BCP 47 language tag (not the full registry of valid codes). `output_type` is `title` or `summary`. Configurable per-service character limits default to 1–300 inclusive, and the model also enforces an absolute validation cap of 10,000.

The optional per-request `min_chars` (default `1`) is a **preferred** lower bound,
not a mandatory response length. It must be between 1 and `max_chars`.
A shorter meaningful label succeeds unchanged with warning
`below_preferred_min_chars`; it does not trigger a rewrite or failure.
`max_chars` remains a hard upper bound. The instructions favor what
a function does over contrastive titles such as "Calculate median, not mean",
but preserve negations that define actual behavior.

Response:

```json
{
  "label": "cache invalid",
  "char_count": 13,
  "language": "en",
  "style": "technical",
  "output_type": "title",
  "provider": "mock",
  "warnings": ["mock_provider: synthetic name formatting, not semantic AI", "below_preferred_min_chars"]
}
```

The sample label is 13 Unicode code points long, below the requested preferred minimum of 15, so the informational `below_preferred_min_chars` warning is included. This is an example **mock-mode** response. In real mode the provider must decide the semantics of `cache_invalid` from context. A bare negation should not be silently inverted. The `char_count` field is the count of Unicode code points in the normalized output.

## POST /v1/labels/batch

Body: `{ "items": [<LabelRequest>, <LabelRequest>] }`. `items` must be non-empty. Each entry is validated separately (if a dictionary) so that one malformed item can result in an individual error. Items are returned in their original order.

```json
{
  "items": [
    {"index": 0, "result": {"label": "example", "char_count": 7, "language": "en", "style": "neutral", "output_type": "title", "provider": "mock", "warnings": ["mock_provider: synthetic name formatting, not semantic AI"]}, "error": null},
    {"index": 1, "result": null, "error": {"code": "provider_timeout", "message": "AI provider timed out"}}
  ],
  "success_count": 1, "error_count": 1
}
```

Per-item failures do not automatically change the whole-batch HTTP 200 response into an HTTP error. Too many items or malformed overall structure cause HTTP 422. CLI JSONL mode writes each `BatchItem` as its own JSON line and returns a non-zero exit code if any item fails.

## POST /v1/labels/file

Multipart text fields: `name` (required), `kind` (default `document`), `output_type` (default `summary`), `min_chars` (default `1`, advisory), `max_chars` (default `160`), `style` (`neutral`), `language` (`es`), `purpose`, `before`, `after`, plus a required binary part `file` with an allowed text extension. Extension and UTF-8 are validated, binary/NUL content is rejected. File contents are supplied as `source_code` for `.py` or `text` for other allowed file extensions. The upload is never executed, saved or used as a path.

```bash
curl -F name=ProjectArchitecture -F output_type=summary -F max_chars=160 \
  -F file=@docs/architecture.md http://127.0.0.1:8000/v1/labels/file
```

## GET /health

Returns `{"status":"ok","provider":"mock"}` when process is live, regardless of whether the configured real provider can be reached.

## Error matrix

| Status | `error.code` | Meaning |
|---|---|---|
| 401 | FastAPI `detail` | Missing/wrong configured Bearer token |
| 413 | `input_limit_exceeded` | Request / context / file too large |
| 422 | `validation_error` / `invalid_request` | Invalid schema or configured values |
| 429 | FastAPI `detail` | Per-IP local rate limit exceeded |
| 502 | `provider_failure` | Provider errored or returned unusable response |
| 503 | `provider_unavailable` | Provider not installed, selected, or available |
| 504 | `provider_timeout` | Provider call timeout |

Error bodies do not echo raw input or provider exception strings. HTTP JSON requests can still be observed by infrastructure outside this service (e.g., reverse proxies); configure those separately.

## OpenAPI schema snapshot

The running application exposes the canonical schema at `GET /openapi.json`. The tracked [`docs/openapi.json`](openapi.json) is a snapshot for documentation and tooling; it must be refreshed when request models or HTTP endpoints change. In particular, both `LabelRequest` and the multipart file endpoint accept an optional `min_chars` field (default `1`; advisory).

To regenerate the snapshot from the installed project environment, review the resulting diff, and run the test suite:

```bash
python -c "import json; from pathlib import Path; from p4_semantic_labeler.interfaces.api import app; Path('docs/openapi.json').write_text(json.dumps(app.openapi(), indent=2, ensure_ascii=False) + '\n', encoding='utf-8')"
```

OpenAPI describes request and response shapes; operational details such as optional Bearer authentication, rate limits and provider availability are explained in this document and in [Security](../SECURITY.md).
